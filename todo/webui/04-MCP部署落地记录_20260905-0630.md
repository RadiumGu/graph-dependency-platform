## 0. 关于 Docker

用户要求「没有 docker，你装一个」。**装不了，但也不需要装。**

沙箱设置了 `no new privileges` 标志，`sudo` 被内核级挡住（不是缺包）：

```
sudo: The "no new privileges" flag is set, which prevents sudo from running as root.
```

本机也没有任何容器工具（docker / podman / buildah / nerdctl / finch 全无），
没有 `/var/run/docker.sock`。

**改用 AgentCore 的「直接代码部署」**：zip（含 Linux arm64 依赖）→ S3 →
`codeConfiguration` + `PYTHON_3_12` + entryPoint，完全跳过容器与 ECR。
`mcp/Dockerfile` 保留，供将来有 Docker 环境时走容器路径（两者共用同一份代码）。

## 3. 踩到并解决的三个问题

**① `entryPoint` 不接受命令数组。** 先传 `["python","main.py"]` 被拒：

```
Invalid entrypoint value. Your entrypoint is either empty, contains spaces,
starts with /, ~, ., .., or has multiple dots.
```

正确形态是 `["main.py"]` —— 托管运行时自己调用解释器，第一个元素不能是
`python`。（CDK 文档里 `['opentelemetry-instrument','main.py']` 的写法
在这个 API 版本下走不通。）

**② SigV4 调用需要 `Accept` 含 `text/event-stream`。** 只传
`--accept application/json` 报 HTTP 406。MCP 是 streamable-HTTP，
必须 `application/json, text/event-stream`。

**③ 扁平部署下契约版本读不到。** `build_default_server()` 原来只在
`dirname(here)/profiles/` 找 `graph_contract.yaml`；直接代码部署的 zip 是
平铺的，正确位置是 `here/profiles/`，于是 `_provenance.graph_contract_version`
静默变成 `"unknown"`——而那个字段正是给 agent 判断数据新旧用的。
已改为按候选列表查找并在都找不到时记 warning（不再静默）。

## 5. 注意事项

**验证判定在持续变化。** 同一天内实测四次：16.82% → 13.08% → 12.15% → 11.21%，
`refuted` 从 3 条归零。原因是 2026-09-05 引入的**独立证据门禁**——
只要该边被任何独立观测源看到过（DeepFlow 调用计数非零），就永不得判 refuted。
MCP server 的 instructions 里已写明这道门禁，免得 agent 把 `refuted=0`
读成「这套机制没在跑」。

**client secret 的位置。** 已写入 DevOps Agent 的服务注册；需要时可用
`aws cognito-idp describe-user-pool-client --user-pool-id ap-northeast-1_Dwd1wVX7j
--client-id 2u5s7r3gprc8mo86890sdi1h7t` 取回。本文档与会话记录中都未回显它。

**更新代码的流程：**

```bash
bash mcp/build_package.sh /tmp/pkg.zip
aws s3 cp /tmp/pkg.zip s3://m2m-926093770964-ap-northeast-1/graphdp-mcp/pkg-$(date +%Y%m%d-%H%M%S).zip
aws bedrock-agentcore-control update-agent-runtime --region ap-northeast-1 \
  --agent-runtime-id graph_dependency_mcp-12Vg2Z9XXu \
  --agent-runtime-artifact '{"codeConfiguration":{"code":{"s3":{"bucket":"...","prefix":"<新 key>"}},"runtime":"PYTHON_3_12","entryPoint":["main.py"]}}' \
  --role-arn arn:aws:iam::926093770964:role/GraphDpMcpAgentCoreRole \
  --protocol-configuration '{"serverProtocol":"MCP"}' \
  --network-configuration <同上> --authorizer-configuration <同上> \
  --environment-variables <同上>
```

⚠️ `update-agent-runtime` 需要把**全部**配置块重传，只传 artifact 会把
authorizer / network 清掉——本次就踩过：第一次创建时为隔离 entryPoint 变量
临时去掉了 `--authorizer-configuration`，结果 Runtime v1 没有 JWT authorizer，
必须靠 v2 补回。
